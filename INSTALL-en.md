# Installation: Zhao

1. Extract this bundle.
2. Open the custom-pet flow in Codex / ChatGPT Work Pets.
3. Upload `zhao-pet-v2.png` from this folder; do not upload the ZIP.
4. Follow the interface to name, save, and select the pet.

This is the complete v2 sprite sheet used by Pets, with nine animation states and 16 look directions. The 16 directions occupy the final two rows. This ZIP is not a standalone app or a directly importable installer.
