# Zhao — Animated ChatGPT Pets companion

An unofficial, AI-assisted fan-made animated pet asset for ChatGPT Work's Pets feature. This repository contains the sprite sheet and motion preview, not a standalone desktop pet application.

## Files

- `zhao-pet-v2.png` — transparent RGBA Pets v2 sprite sheet (1536 × 2288 px; 8 × 11 cells; 192 × 208 px per cell).
- `animation-preview.gif` — animation preview across all states.

The sheet contains nine animation states and sixteen clockwise look-direction frames.

## Use

Download `zhao-pet-v2.png` and upload it through the custom-pet creation flow in ChatGPT Work's Pets feature. A Pets interface that supports custom v2 pets is required; no separate desktop app is needed.

## Validation

The final sheet passed the Pets v2 structural preflight (`valid: true`) and quality validation (`ok: true`). Its SHA-256 is `bb7c4129ea4f415035494be44299ed0477bf65ff6e270418c726f460fda848eb`.
